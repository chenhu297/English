第十一讲 · 特殊句式(2/3)

第十一讲三块：虚拟 ✅ → 倒装(本篇) → 强调。倒装主要是读懂(阅读里语序反常别慌)+ 偶尔写作出彩。核心：把(部分)谓语搬到主语前。

一句话抓本质：正常语序是主语 + 谓语；倒装就是把谓语(或助动词)提到主语前面。分两种：全部倒装(整个动词提前)和部分倒装(只提助动词，像疑问句)。

1全部倒装 · 整个谓语提到主语前

主语是名词时，可以把整个动词甩到它前面。常见两类：

Here comes the bus. ／ On the top of the mountain lies a temple.

公交来了。／ 山顶上坐落着一座庙。(here/地点状语提前 → 动词提前)

⚠️ 主语是代词就不倒装

Here comes the bus. ✓ 但 Here it comes.(不是 Here comes it)——主语是代词 it 时，动词不提前。

🔑 There be 句型(雅思必考的全部倒装)

规则

There + be + 真正的主语 +(地点/状语)，表示"有"。be 跟 there 后面那个真主语走——定单复数、定时态。

🟦 There are two key factors behind this trend.

这个趋势背后有两个关键因素。(剑 10 · 主语 factors 复数 → are)

🟦 …there has been a dichotomy between the guest environment and the working conditions.

在……之间一直存在割裂。(剑 14 · 现在完成)

要表达There + be
现在有There is / are …
过去有There was / were …
将会有There will be …
可能有There might be / may be …
现在已经有(现在完成)There has been / have been …

2部分倒装 · 只把助动词提前(像疑问句)

规则 · 什么时候用

结构 = 触发词 + 助动词/be/情态 + 主语 + 主要动词(和一般疑问句语序一样)。触发场景主要三类：

① 否定 / 半否定词放句首

never / little / hardly / seldom / rarely / not only…but also / no sooner…than / not until… 放句首 → 部分倒装。

🟦 Never before has the planet's linguistic diversity shrunk at such a pace.

地球的语言多样性从未以如此速度萎缩。(剑 4)

🟦 Not only are evolutionary throwbacks possible, they sometimes play an important role…

返祖不仅可能，有时还很重要。(剑 9)

🟩 Not only did we hit the deadline, but we also cut costs.

我们不仅赶上了截止日期，还降低了成本。(工作)

② only + 状语 放句首

🟦 Only in this way can we learn English well.

只有这样我们才能学好英语。

🟩 Only after testing did we release the update.

只有在测试之后我们才发布更新。(工作)

③ 虚拟条件句省略 if(接虚拟)

把 if 去掉，将 were / had / should 提到主语前。

Had he played last season, we would have won. ＝ If he had played…

要是他上赛季上场了，我们就赢了。

Were I you, I'd double-check the numbers. ＝ If I were you…

我要是你，会再核对一遍数字。

3高频易错

⚠️ 高频错

1. 部分倒装只提"助动词"，实义动词留原位、还原第三人称/时态
✗ Never I saw such a thing. → ✓ Never did I see such a thing.(saw→did see)
✗ Little he cares. → ✓ Little does he care.

2. There be 的 be 跟错了数(要跟后面真主语)
✗ There is two issues. → ✓ There are two issues.

3. 全部倒装误用于代词主语
✗ Here comes it. → ✓ Here it comes.

💡 口诀

否定 only 放句首，助动词提到主语前(像问句)；There be 记牢：be 跟真主语。读到语序反常，先找被"甩到后面"的主语，句子就顺了。

📝 自测 · 田静课堂练习

A：填 There be 的 be；B：改成部分倒装。

A1. There ______(过去有) significant activities in almost every state.

were(activities 复数 + 过去)

A2. There ______(将会有) change — new jobs, new products, new services.

will be

A3. There ______(现在的之前有) controversial views about its implications.

have been(现在完成 + views 复数)

A4. There ______(可能有) more matches in the database.

might be / may be

B1. You will never know the truth. →（Never 开头）

Never will you know the truth.

B2. He cares little for my words. →（Little 开头）

Little does he care for my words.(cares → does care)

B3. I had no sooner got the invitation than I refused. →（No sooner 开头）

No sooner had I got the invitation than I refused.

B4. We can learn English well only in this way. →（Only in this way 开头）

Only in this way can we learn English well.

B5. He achieved his goal only by working hard. →（Only by… 开头）

Only by working hard did he achieve his goal.

B6. If he had played last season, we would have won. →（省 if 倒装）

Had he played last season, we would have won.

🗣️ 立刻用出来

倒装偶尔用在工作里能显水平，最实用两个：
· There be 摆事实：There are three things we need to fix before launch.
· Not only… but also(倒装)夸成果：Not only did we ship on time, but we also improved performance.
说一句你工作里的事，我帮你看 There be 的 be、以及部分倒装的助动词提对没。
