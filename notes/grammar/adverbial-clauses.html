复合句 · 状语从句

第二部分 · 如何表达多件事  |  田静 第九讲《复合句》

🎉 第九讲 · 第二部分收官

三大从句最后一个！状语从句其实是从句版的状语——第三讲你用副词、介词短语作状语交代背景，现在用一整个句子来交代时间、原因、条件、让步……9 类看着多，套路就一个：从属连词 + 一句话。真正的考点在几个易错坑（§3）。

一句话抓本质：状语从句 = 从属连词 + 一个完整句子，整体贴在主句上，交代"什么时候 / 为什么 / 什么条件下"发生。位置灵活：可放主句前（加逗号）或后（不加）。

1含义 & 位置

When the deploy finishes, I'll notify you. ＝ I'll notify you when the deploy finishes.

部署完成后我通知你。（从句在前 → 加逗号；在后 → 不用）

规则

状语从句本身是完整的句子（有自己的主谓），靠从属连词挂到主句上。它和主句是主从关系（从句从属于主句），不是并列——这是它跟并列句的根本区别。

2九类状语从句 · 一表看全

红色是常用从属连词，记住连词就能认出是哪类。例句多来自讲义真题：

类别常用从属连词例句
① 时间when, while, as, before, after, since, until, as soon asThings got serious when I became a member…（剑14）
② 地点where, wherever…develop writing where none existed before（剑4）
③ 原因because, since, asHappiness is the goal because it is self-evidently good（剑13）
④ 结果so … that, such … thatThe boy kicked so hard that it nearly fell into the river
⑤ 目的so that, in order thatHe ran so that he might catch the last bus
⑥ 条件if, unless, as long asIf the brain is an engine, bilingualism may help…（剑12）
⑦ 让步although, though, even though, even ifAlthough technologies can reduce demand…, transport keeps increasing（剑10）
⑧ 比较than, as … asBatteries can die faster than we realize
⑨ 方式as, as if, as thoughWhen in Rome, do as Romans do

最常用、最常考的是 时间 · 原因 · 条件 · 让步 四类，先把这四类的连词焊死。

3真正的考点 · 四个易错坑

⚠️ 坑 1（最高频）· 主将从现

时间 / 条件状语从句里，如果主句是将来时，从句用一般现在代替将来（不能用 will）。
✗ When the data will come in, we'll analyze it. → ✓ When the data comes in, we'll analyze it.
✗ If it will rain, we'll cancel. → ✓ If it rains, we'll cancel.
（这条在 时态精讲 §5 也标过——从句管"条件"，主句才管"将来"。）

⚠️ 坑 2 · because / so 不能连用，although / but 也不能

中文"因为…所以…""虽然…但是…"是成对的；英文只能留一个——因为 because/although 是从属连词（引导从句），so/but 是并列连词（见并列句），一个句子里只能用一种连法。

✗ Because I was tired, so I left. → ✓ Because I was tired, I left. ／ I was tired, so I left.
✗ Although it rained, but we went. → ✓ Although it rained, we went. ／ It rained, but we went.

⚠️ 坑 3 · so … that vs such … that

so + 形容词 / 副词 + that；such + (a/an) + 形容词 + 名词 + that。
It was so urgent that we hotfixed it. ／ It was such an urgent bug that we hotfixed it.

⚠️ 坑 4 · since / as 一词两义

since：既表"自从"（时间），又表"既然"（原因）——看语境。
Since 2020 the team has grown.（自从）／ Since you're here, let's start.（既然）

💡 口诀

从属连词 + 一句话 = 状语从句。9 类先抓时间 / 原因 / 条件 / 让步四类连词；写的时候盯两点：时间条件从句"主将从现"，because/although 不跟 so/but 搭伙。

📝 自测（先想再展开）

1–4 判断状语从句类别（讲义真题）；5–6 改错 / 填空。

1. They cannot refuse to speak English if most commercial activity is in English.（剑4）

条件状语从句（if）。

2. It is far more ambitious than it looks.（剑10）

比较状语从句（than）。

3. …more signs of disease than their counterparts, even though their behaviour was the same.（剑12）

让步状语从句（even though "即使 / 尽管"）。

4. Day length is an excellent cue, because it provides a predictable pattern.（剑5）

原因状语从句（because）。

5. 改错：When the meeting will start, we will begin.

✓ When the meeting starts, we will begin. —— 时间从句"主将从现"，从句不用 will。

6. 改错：Because the API broke, so we rolled back.

✓ Because the API broke, we rolled back.（或 The API broke, so we rolled back.）—— because 和 so 只能留一个。

🗣️ 立刻用出来

状语从句让你把"逻辑关系"说清楚。工作里最常用这四类，各来一句你手头的事：
· 时间：When the tests pass, I'll merge it.（注意主将从现！）
· 原因：We postponed the launch because the data wasn't ready.
· 条件：If the client approves, we'll start next week.
· 让步：Although it's risky, I think it's worth trying.
说给我，我重点盯两个坑：主将从现、because/although 别再加 so/but。
