谓语动词的语态（被动语态）

第一部分 · 如何表达一件事  |  田静 第二讲《简单句的核心变化》

第二讲进度

第二讲三件套：时态 ✅ → 语态（本篇） ✅ → 情态 ✅。被动语态会大量用到时态——8 个时态的变形忘了就回时态精讲翻一眼。

一句话抓本质：主动 = 主语做动作；被动 = 主语挨动作（被改变、被使用、被完成）。英文被动只有一个公式：be + done。雅思阅读里被动句铺天盖地，写作用对被动立刻显得客观、像样。

1什么时候用被动

规则 · 三种典型场景

① 不知道 / 不必说谁做的；② 想强调承受者，把它放到主语位置；③ 正式、客观的表达（学术文章、工作邮件高频）。

My laptop was stolen.

我电脑被偷了。（不知道谁偷的——说不出"谁做"，只能被动）

The issue has been fixed.

问题已修复。（重点是"问题修没修"，谁修的不重要——工作邮件标准句式）

2构成 · be + done 各管什么

be + done

  • done → ① 被动的动作——过去分词，从头到尾不变形
  • be → ② 被动的时间——时态全靠 be 变（is → was → will be → has been…）
  • be → ③ 主语的单复数——is / are、was / were 跟着主语走
💡 主动改被动 · 三步

① 宾语提前当主语 → ② 动词变 be + done（be 对齐原来的时态）→ ③ 原主语用 by… 带出（多数时候直接省）。
We finished the report. → The report was finished (by us).

⚠️ 前提

只有及物动词才有被动——动作得有承受者。不及物动词没有被动：happen / appear / disappear / take place 是"自己发生"，✗ was happened。（动词及物不及物，回看第一讲。）

3被动 × 时态 · 一张表全搞定

被动遇上时态，动的永远是 be，done 纹丝不动。下表就是田静课上的"环境被改变"八连——盯着红色部分看：

时态公式例句中文
一般过去was / were + doneThe environment was changed.环境过去被改变了。
一般现在am / is / are + doneThe environment is changed.环境现在被改变了。
一般将来will be + doneThe environment will be changed.环境将会被改变。
过去将来would be + doneThe environment would be changed.环境过去将会被改变。
过去进行was / were being + doneThe environment was being changed.环境过去正在被改变。
现在进行is / are being + doneThe environment is being changed.环境现在正在被改变。
过去完成had been + doneThe environment had been changed.环境过去已经（过去的之前）被改变了。
现在完成have / has been + doneThe environment has been changed.环境现在已经（现在的之前）被改变了。

真题里长这样（讲义例句）

🟦 International commerce was therefore dominated by raw materials…

因此国际贸易（过去）被原材料主导。（剑 6 · 一般过去被动）

🟦 This representation has commonly been limited to guest experiences.

这种呈现通常被局限在客户体验上。（剑 14 · 现在完成被动）

🟦 The best information… is now being obtained from the 'archaeology of the living body'.

最有价值的信息现在正从"活体考古"中获得。（剑 7 · 现在进行被动）

🟩 The meeting was rescheduled to Friday.

会议改到了周五。（工作高频：说变动）

🟩 The new version has been deployed — please verify.

新版本已发布——请验证。（工作高频：报进度）

4被动 × 情态 · 情态动词 + be + done

规则

情态动词（must / can / may / should…）+ be + done。情态后面的 be 永远用原形，不随时态、单复数变。

🟦 The environment here must be changed. ／ can be changed. ／ may be changed. ／ should be changed.

这里的环境必须 / 能够 / 可能 / 应该被改变。（田静课堂例）

🟦 The ambitious objective can only be fully achieved by 2020…

这一宏伟目标最早只能在 2020 年完全实现。（剑 10）

🟩 This issue must be resolved before the release.

这个问题必须在发布前解决。（工作高频：提要求）

5高频易错

⚠️ 中国学习者高频错

1. 中文没说"被"，英文照样要被动（最大坑）
中文爱省"被"字："会议推迟了"其实是"会议被推迟了"。
✗ The meeting postponed. → ✓ The meeting was postponed.

2. 漏 be
✗ The problem solved quickly. → ✓ The problem was solved quickly.

3. 不及物动词强行被动
✗ The accident was happened last night. → ✓ The accident happened last night.

4. 情态后面 be 忘了用原形
✗ The task must is finished today. → ✓ The task must be finished today.

5. be 不跟主语单复数 / 时态走
✗ The files was sent yesterday. → ✓ The files were sent yesterday.

💡 口诀

动作给 done（永远不变），时间和单复数全给 be。写句子先问：主语是"做的人"还是"挨的事"？是"挨"的，就上 be + done；再按时态把 be 变形。

📝 自测（先想再展开）

1–5 是田静课堂练习（填入合适的被动语态）；6–8 是讲义真题识别（找出被动并判断时态）。

1. Our morning paper ______ (read) by over 200,000 people every day.

is read — 一般现在被动。every day 表习惯；主语 paper 单数 → is。

2. Last night my favorite TV program ______ (interrupt) by a special news bulletin.

was interrupted — 一般过去被动。last night 是过去时间点。

3. His bike ______ (repair) by his grandfather tomorrow.

will be repaired — 一般将来被动。tomorrow → will be + done。

4. So far the new machine ______ (use) in our factory for two weeks.

has been used — 现在完成被动。so far / for two weeks = 持续到现在。

5. 天气不能被人们所控制。 Weather ______ by people.

cannot be controlled — 情态 + 被动。情态后 be 用原形。

6.（真题识别）Such a change cannot be achieved overnight. (剑 10)

被动部分：cannot be achieved = 情态 + be + done。这样的变革不可能一蹴而就。

7.（真题识别）Down the centuries, thousands of wells were constructed throughout north-western India. (剑 10)

被动部分：were constructed = 一般过去被动；主语 wells 复数 → were。数百年间，西北印度修建了成千上万口井。

8.（真题识别）Somehow the importance of play has been lost in recent decades. (剑 14)

被动部分：has been lost = 现在完成被动。近几十年，玩耍的重要性不知不觉被忽视了。

🗣️ 立刻用出来

被动是工作邮件 / 站会的高频句式。用你手头的事各说 1 句：
· 现在完成被动报进度：The issue has been fixed. ／ The PR has been merged.
· 一般过去被动说变动：The meeting was moved to 3 pm.
· 情态被动提要求：This must be done by Friday.
